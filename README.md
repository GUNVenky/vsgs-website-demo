# Demo Family Store – Website Portfolio

A responsive grocery-store and online-services website demonstration.

## Included features

- Product categories and promotional sections
- Store services presentation
- Billing and estimate interface
- Local browser storage for demo data
- Responsive desktop and mobile layout

## Privacy note

This portfolio copy uses fictional branding and contact details. Do not add real customer records, supplier records, administrator credentials, production database exports, private keys, or other confidential information.

## Firebase note

Cloud writes are disabled in this public demonstration copy. Configure your own Firebase project and security rules before enabling cloud functionality.


## Demo authentication
This public portfolio version opens the demo admin interface without real administrator authentication. It is intended for demonstration only and must not be connected to production data or a production Firebase project.
